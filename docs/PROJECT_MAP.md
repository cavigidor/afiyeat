---

## 2. Stack

- **Frontend:** React 18 + TypeScript + Vite, Tailwind + shadcn/ui, React Router, TanStack Query.
- **Native:** Capacitor 8, using Swift Package Manager (`ios/App/CapApp-SPM/Package.swift`), not CocoaPods.
- **Data:** Supabase (Postgres + RLS, Auth, Storage, Edge Functions in Deno).
- **Maps and place search:** Mapbox (GL JS on the client, Search Box API via edge functions).
- **No paid SDKs.** Capgo (live updates) is installed but switched off (`autoUpdate: 'off'`) and is due for removal.

## 6. Working rules (do not plan around breaking these)

1. Don't break afiyeat.com. Native-only code goes behind `isNative` / `src/lib/native.ts`.
2. Database changes go in a new migration only, and must be backwards-compatible. No speculative schema changes.
3. Never put service keys or secrets in the client. `.env` holds only the public Supabase URL and the publishable key.
4. No paid third-party SDK or service without flagging it first.
5. No cash or monetary referral rewards (App Store and fraud risk). Passport perks only.
6. Never hand-edit `src/integrations/supabase/types.ts`. New RPCs are called through `untypedRpc` in `lib/passport.ts`.
7. Verify with `npm run typecheck`, not plain `tsc`: the root tsconfig checks 0 files.
8. In git, use explicit `git add <paths>`, never `-A`. Run no destructive git commands.
9. After native changes: `npm run build && npx cap sync ios`, then rebuild in Xcode. If Xcode shows "Missing package product", use File → Packages → Reset Package Caches.
